# Milestone 1 acceptance gate

Do not begin implementation until architecture and design-system proposals are explicitly approved.

## Content and visual quality

- [ ] Desktop preserves cinematic left identity/right engineering scene, not generic SaaS cards.
- [ ] Serif name and Explore Work CTA are immediately visible at agreed desktop/mobile sizes.
- [ ] Editorial spacing, quiet surfaces, restrained amber/blue and readable mono labels.
- [ ] AEGIS and Paradox have flagship placement; Synapse, Bettr, research remain discoverable.
- [ ] Selected work, experience preview, research preview, contact/footer present only approved facts.
- [ ] Incoming Accenture Summer 2027 is unmistakably future; no award, FDE, publication, or deployment inventions.
- [ ] Resume/contact links publish only after real approved destinations exist; no fake buttons.
- [ ] Abstract diagrams distinguished from real screenshots; asset provenance recorded.

## Functionality and accessibility

- [ ] Navigation and every CTA resolve to implemented destinations or useful in-page sections.
- [ ] Five project worlds are real semantic interactive elements with useful previews/navigation.
- [ ] Hover and keyboard focus reveal the same information; Tab/Enter, touch, and Escape tested as applicable.
- [ ] Mobile composition works at 360/390px without horizontal page overflow.
- [ ] Tablet/desktop checked at 768/1280/1440px; 200% zoom remains usable.
- [ ] Reduced motion and JavaScript-disabled fallback preserve information and links.
- [ ] Skip link, headings, landmarks, visible focus, labels, contrast, target size reviewed; automated axe scan run.
- [ ] No audio, scroll hijack, perpetual particles, layout-shifting artwork, or canvas-only controls.

## Engineering and review evidence

- [ ] pnpm typecheck, pnpm lint, pnpm test, pnpm build pass after integration.
- [ ] GitHub Actions passes on integrated commit.
- [ ] Browser screenshots saved for desktop/mobile and compared to the three-reference hierarchy.
- [ ] Performance measured with named device/network settings; budgets in architecture reviewed.
- [ ] No errors in browser console; assets have fixed dimensions and no blocking font fetch.
- [ ] Integration lead reviews code, actual browser result, and factual accuracy before reporting completion.
- [ ] Owner reviews M1 before further visual expansion; AI assistant/dashboard remain deferred.
